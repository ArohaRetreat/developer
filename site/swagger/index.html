Explore the versioned API and execute requests with your scoped Aroha integration token.

Select the API server, choose Authorize, and paste your token without the Bearer prefix. Preprod is selected initially and remains restricted to approved testers. Requests run only when you select Execute.

A read-only MCP token permits its allowed reads. Write operations require an integration token with the matching write scope and your current role. Tokens are held in memory for this page session.
