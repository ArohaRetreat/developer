MCP server · npm

A read-only retreat companion.

Connect an MCP-compatible assistant to the information your Aroha account is allowed to read. Business writes stay outside the MCP surface.

View npm package ↗Source on GitHub

Install through your MCP host

Requires Node 22 or later. Create a read-only token, store it in a private file with chmod 600, then add this configuration to your MCP host. Your host's configuration location varies.

MCP host configuration
{
  "mcpServers": {
    "aroha": {
      "command": "npx",
      "args": [
        "--yes",
        "@theharithsa/aroha-mcp@0.1.0"
      ],
      "env": {
        "AROHA_API_URL": "https://aroha-retreat-preprod.web.app/api/external/v1",
        "AROHA_API_TOKEN_FILE": "/absolute/private/path/aroha-token"
      }
    }
  }
}

Available read tools

ToolReads
aroha_get_runtimeEnvironment and allowed capabilities
aroha_get_availabilityComputed availability; no hold or quote
aroha_get_calendarAggregate dates; no guest identities
aroha_list_reservationsOne redacted permitted page
aroha_get_reservationOne permitted reservation
aroha_list_unitsOperating room metadata
aroha_get_unitOne room record
aroha_get_published_contentPublished website copy only
aroha_list_communicationsDelivery status; no bodies or recipients

Discovery is filtered by your token's actual capabilities. Each tool has bounded inputs and results. The server never automatically reads every page.

Read-only at every boundary

The registry exposes GET mappings only. Credentials have read-only scopes and an API-enforced operation ceiling. The adapter has no direct Firestore access, generic fetch tool, upload, quote creation, booking mutation or email-send tool. Contact information, private notes, feedback and document binaries are excluded.

Telemetry and protocol

Every tool call records a real SDK trace, count, duration and completion log. Configure your own approved OTLP destination to export signals; no Aroha/Dynatrace secret is bundled. See telemetry setup. Stdout is reserved for JSON-RPC; completion logs use stderr. This release uses stdio. Remote HTTP/OAuth is deferred.
